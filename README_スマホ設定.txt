構文辞書アプリ 完成版

【できること】
・スマホのホーム画面からアプリのように起動
・JavaScript / React / Node.js / Express / Python
・検索、カテゴリ切替、ランダム、お気に入り
・ダークモード
・Service Workerによるキャッシュ
・一度オンラインで読み込んだ後はオフライン利用しやすい構成

【重要】
PWAとして「ホーム画面に追加」するには、通常 HTTPS のWebサイトとして公開する必要があります。
PCのローカルファイル（file://）を開くだけでは、PWAのインストール機能は正常に使えない場合があります。

【スマホでの使い方】
1. このフォルダ一式をHTTPSで公開する
2. スマホのブラウザで index.html を開く
3. iPhoneなら共有メニュー → 「ホーム画面に追加」
4. Android Chromeならメニュー → 「ホーム画面に追加」または「アプリをインストール」
5. ホーム画面の「構文辞書」をタップ
6. アプリのような画面で起動
7. 一度読み込んでおけば、キャッシュされた範囲はオフラインでも利用可能

【注意】
「完全に自分だけ」にしたい場合、公開先のアクセス制限が必要です。
